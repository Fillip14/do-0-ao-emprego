# web — Do 0 ao Emprego
App web para estudo de front-end

## Como rodar

1. npm install
2. npm run dev        # sobe em http://localhost:5173
3. npm run typecheck  # roda tsc -b --noEmit, tem que ficar limpo antes de commitar

## Estrutura de pastas

